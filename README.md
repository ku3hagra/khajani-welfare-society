# Khajani Welfare Society — Greenfield Website

Production target: https://khajaniwelfaresociety.com

This branch is a clean greenfield build. The legacy `main` branch is reference-only and remains untouched.

Architecture: Next.js App Router + TypeScript, Sanity CMS, Vercel deployment, SEO-first metadata, controlled editability, real Khajani imagery only.

Media hard rules: reject every image containing `SDTT`; premises imagery requires verification; large archival originals and routine editable media belong in Sanity rather than Git.
